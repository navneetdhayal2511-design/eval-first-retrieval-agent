# On-call rotation

The platform team keeps a primary and a secondary for the public API.

## Handoff

The primary on-call rotation changes every week. Handoff is Monday at 10:00 America/Los_Angeles. The outgoing primary writes a handoff note in the on-call channel before that time.

## Page acknowledgment

The primary acknowledges a page within 15 minutes. If there is no acknowledgment, the secondary is paged automatically.

## Severity definitions

A Sev-1 page means customer data exposure or a complete API outage. A Sev-2 page means a single region is degraded but a workaround exists.

## On-call pay

Primary on-call pay is 400 dollars for a weekday week and 700 dollars when the week includes the weekend shift.
